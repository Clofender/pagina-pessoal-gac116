Esta é minha Página Pessoal, desenvolvida para a Atividade Prática 2 da disciplina GAC116 - Programação Web. O projeto apresenta minha formação, trajetória, habilidades, interesses e alguns projetos desenvolvidos.

O trabalho possui duas versões equivalentes para comparar abordagens de estilização: uma com Bootstrap 5.3 e outra com Tailwind CSS. As duas versões utilizam HTML, CSS e JavaScript, são responsivas e oferecem alternância entre tema claro e tema escuro.

## ✨ Funcionalidades Implementadas

- Página inicial com apresentação pessoal, foto, curso e objetivo profissional.
- Seções de sobre, habilidades, projetos, interesses e contato.
- Navegação por âncoras com menu responsivo para dispositivos móveis.
- Tema claro e escuro com preferência salva no `localStorage`.
- Layout adaptável para celulares, tablets e desktops.
- Links para GitHub, LinkedIn, Instagram e repositórios de projetos.
- Página inicial na raiz para acessar as duas versões publicadas.

## 🛠️ Tecnologias Utilizadas

- HTML5 para a estrutura semântica das páginas.
- CSS3 para ajustes visuais e identidade do projeto.
- JavaScript para tema, menu mobile e ano automático no rodapé.
- Bootstrap 5.3 na versão `code/`.
- Tailwind CSS na versão `page/`.
- Font Awesome para os ícones.
- GitHub Pages para publicação.

## 🚀 Como Executar Localmente

Não há dependências para instalar. Basta clonar o repositório e iniciar um servidor HTTP local:

```bash
git clone https://github.com/Clofender/pagina-pessoal-gac116.git
cd pagina-pessoal-gac116
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000` no navegador e escolha a versão desejada. Um servidor local é recomendado porque evita restrições de carregamento de arquivos e reproduz melhor o ambiente do GitHub Pages.

## 🌐 Publicação

O projeto foi organizado para publicação pelo GitHub Pages. Nas configurações do repositório, selecione `Deploy from a branch`, escolha a branch `main` e a pasta `/ (root)`. A página inicial exibirá os links para as versões Bootstrap e Tailwind.
